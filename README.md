# ☕ BIGSHOT — Coffee Community

> 🚧 A real-world website project, built from scratch — one page at a time.

**BIGSHOT Coffee Community** is a modern, multi-page website being developed for a real café in Dehradun, India.

The project combines **clean frontend development, interactive UI, animations, responsive design and a strong visual identity** to create a digital experience around coffee, music, cars and community.

---

## ✨ What I'm Building

🎨 Premium & minimal visual design  
🧭 Interactive navigation experience  
🎞️ CSS animations and transitions  
💿 Interactive vinyl-inspired hero section  
🖱️ Mouse-based interactions & parallax effects  
📜 Scroll-based animations  
📱 Responsive layouts for desktop & mobile  
🧩 Multi-page website architecture  
🌐 Real-world business website
